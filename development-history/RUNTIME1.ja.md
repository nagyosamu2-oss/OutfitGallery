# Runtime1 — 対応ランタイム検証版（DLL 1.0.18.6）

UI2 を基に、重ね着の 1.6.1170 専用制限を置き換えた検証用ビルドです。
全バージョンの実機動作確認が完了した公開版ではありません。

## 変更

- SE / AE の呼出先を分けて Address Library から解決します。公開版と同じ CommonLibSSE-NG 10.1.0 と対象一覧を維持しています。
- 固定位置への書込みをやめ、起動時に PE の関数範囲内の到達可能な命令をデコードします。
- 重ね着側は「着用走査の呼出先」と「着用 visitor の vtable 参照」の両方を照合します。判定用の別 visitor を重ね着処理と取り違えないためです。
- 古い版のラッパー関数は、親関数から呼ばれている場合のみ候補に含めます。候補が複数・未検出・解析不能なら、書込み前に重ね着だけを無効にして理由をログに残します。
- 既存の IED 呼出チェーン検証を維持します。未知のフックを迂回しません。
- プレイヤー一人称・フォロワー表示・保存復元・UI・初期値・通常着替えの処理は UI2 から維持します。
- GOG は EXE バージョン 1.6.1179.0 と SKSE 識別値 1.6.1179.1 を区別しています。

## まず現在の 1.6.1170 で確認

1. UI2 と同時に有効にせず、この ZIP に切り替えます。設定のリネームは不要です。
2. 起動後、プレイヤーの重ね着（一人称／三人称）と解除を確認します。
3. フォロワーの重ね着と標準装備へのリセットを確認します。
4. 重ね着中のセーブ→ロードも確認します。
5. 終了後、次の起動で上書きされる前に OutfitGallery.log を保存してください。

成功時は `RUNTIME1 validated runtime=...` と `RUNTIME1 transmog hooks installed on ...` が出ます。
重ね着が出ない場合は `RUNTIME1 transmog disabled: ...` を含むログが次の切り分け材料です。
既存の別 MOD との検証により停止した場合は従来の警告も出ます。
SKSE / Address Library / SKSE Menu Framework は、それぞれ対象のゲーム版に適合するものが必要です。

## 開発確認

ビルド、42 件の自動テスト、DLL 内の 7 対象一覧と GOG 識別値の照合を実施。
命令境界、即値内の偽 CALL、到達不能コード、重複候補、誤った visitor、途中命令への分岐、切れた命令、および既存 IED チェーンの拒否条件をテストしています。
中断時の runtime1 ソースは別 ZIP に保存。元の skin13 および配布済み diag1〜UI2 は変更していません。
公開版の対応一覧に重ね着まで含めて記載する前に、各ランタイムでの起動・適用・解除確認が必要です。
