# Runtime4 — 重ね着の制限と停止理由の見直し（DLL 1.0.18.9）

## 変更内容

- 重ね着の起動時に、FittingRoom / ApparelPreview / SkyrimFittingSystem が読み込まれているという理由だけで停止する判定を削除しました。Skyrim Outfit System の名前による判定は Runtime3 で削除済みです。
- 呼出位置を特定でき、通常の関数呼出しを保っている場合は、他DLLの処理を引き継げるようにしました。髪の表示判定と装備描画の両方で、元の呼出先を保持します。
- 重ね着を準備できなかった場合、ボタンにマウスを重ねると理由を表示します。クリック時も画面内に同じ理由を表示します。原因をゲームバージョンだけの問題と誤表示しません。
- プレイヤーの自動重ね着だけに残っていた三人称限定を解除しました。一人称中も自動切替の対象です。通常の待機時間、攻撃中などの待機条件は維持します。
- 右クリックの「見た目だけ試着」に残っていた「三人称限定・試験8」を削除しました。

通常着替えの処理、重ね着の描画本体、フォロワーの適用・解除、保存復元、設定の初期値は維持しています。公開版、skin13、Runtime3以前のソースと配布物は変更していません。

## 今回確認した Skyrim Outfit System について

Steam 1.5.97 / Skyrim Outfit System v0.6.0 の実測では、髪の表示判定と装備描画の2箇所が、専用コードへジャンプする方式に変更されていました。この方式は通常の関数呼出しとして引き継げないため、Runtime4でも重ね着を開始しません。併用対応を完了した版ではありません。

今回の保存データでは、次の理由と関連DLLを特定できることを確認しました。

> 髪の表示処理が、この版では連携できない方式で変更されています。関連DLL: SkyrimOutfitSystemSE.dll

DLLが存在するだけの拒否と、実際の接続方式が未対応であることを区別します。他MODの処理を無条件に上書きする変更はありません。

## 対応範囲・確認状況

対象バージョンの一覧は維持しています。

- Steam: 1.5.97 / 1.6.353 / 1.6.640 / 1.6.1130 / 1.6.1170 / 1.7.104
- GOG: 1.6.1179（実機未検証）

他DLLに置き換わった呼出しを実測位置から特定する追加経路は、位置を確認済みの1.5.97と1.6.1170が対象です。他のバージョンでも従来の呼出先に基づく自動特定を維持していますが、任意の他DLLとの連携まで確認済みという意味ではありません。

- x64ビルド成功、回帰テスト44件成功。
- DLLの公開メタデータが1.0.18.9と指定7対象になっていることを確認。
- 保存した1.5.97の実データで、命令の解析から問題のジャンプ箇所とSkyrim Outfit SystemのDLL名を特定できることを確認。
- 通常の関数呼出しを引き継ぐ検証、未対応ジャンプ・循環・読めない接続先の検証を実施。
- Runtime4のゲーム内動作・画面表示・一人称中の自動切替は未検証です。追加した汎用連携も、各MODとの実機互換性は未確認です。

## 入れ替えと確認

ゲームを終了して、旧テスト版の代わりにRuntime4を有効にしてください。設定ファイルの削除・初期化は不要です。ZIPに設定や写真は含めていません。

1. 従来使えた構成で、プレイヤー・フォロワーの重ね着と解除を確認してください。
2. 自動着替えを重ね着モードで有効にし、一人称のまま割当済みの条件へ変えて、自動切替を確認してください。
3. Skyrim Outfit Systemを有効にした構成では、重ね着ボタンのマウスオーバーまたはクリックで停止理由が表示されることを確認できます。この構成で重ね着が有効になることは今回の期待結果に含みません。

起動ログの先頭付近に `RUNTIME4 runtime4 version=1.0.18.9` が出ます。問題があれば、その起動の `OutfitGallery.log` を次の起動前に保存してください。
