# Outfit Gallery 2.2.1-headgear-test1

頭装備を実際に装備したまま重ね着した際、耳に穴が開く・頭が消える症状への試験修正です。ゲーム内の改善は未確認です。公開版2.2.1とは別の試験版です。

## 導入と戻し方

Skyrimを終了してから、公開版2.2.1を導入済みの環境に差し替え用ZIPを導入してください。MO2では別MODとして入れ、OutfitGallery.dllがこの試験版のものになる優先度にしてください。旧診断版・別の差し替えDLLとの重複を避けてください。
変更するゲーム用ファイルはSKSE/Plugins/OutfitGallery.dllだけです。INI、Library.json、写真などは含めません。起動後はギャラリー下部またはログ先頭の2.2.1-headgear-test1表示で判別できます。
戻す場合はゲームを終了し、試験版を無効にして公開版2.2.1のDLLに戻してください。検証には更新前のテスト用セーブを使ってください。

## 優先して確認すること

頭装備を含まない重ね着セットで確認します。

1. 重ね着を適用してから「鉄の兜」を通常のインベントリで着脱し、耳の穴が出ないか確認。
2. 同様に「スチールプレートの兜」を着脱し、頭全体が消えないか確認。
3. 先に実際の兜を装備してから重ね着セットを適用しても、同じように正常か確認。
4. 重ね着を解除し、実際の兜が通常どおり表示されるか確認。
5. 見た目として兜を含む重ね着セットと、ウィッグ・頭装備だけの重ね着が崩れていないか確認。

可能なら、髪型変更なしでまず上記を確認してください。追加確認はフォロワー、頭装備以外の小物だけの重ね着、ロード後、一人称です。
改善しない・一瞬戻って再び欠ける・兜から顔が突き抜ける場合は、その状態でのOutfitGallery.logと、実際の兜名／見た目の頭装備名を共有してください。再起動前のログを保存してください。

## 修正範囲と診断

- 重ね着が隠す実際の兜について、髪だけでなく頭全体の表示判定も見た目に合わせます。
- 非表示にした実際の兜によって隠れた頭・耳のメッシュ区画を復元します。見た目として選んだ兜が隠すべき部分は復元対象から外します。
- 30/43と130/143の区画だけが対象です。全身や切断面の区画を無条件に表示しません。
- 復元はゲームスレッドで行い、再構築ごとに最大4回、150ms間隔の有限な再確認を行います。新たな常時全身探索は追加しません。停止やロード後に古い見た目の処理が残らないよう現在の状態を確認します。
- 新しいフックは追加しません。重ね着が無効な通常装備経路には新しい処理を入れません。
- HEADGEAR1ログに判定・調査対象の区画数・復元数を記録します。対応するAddress Library IDが見つからない場合、区画復元は実行せず警告を残します。

ビルドおよび54/54選択テストは成功しています。既知の環境制約があるTrashVirtualPathSafetyは従来どおり除外しており、成功数に含めません。テストはゲームの描画を実行しないため、修正効果は報告環境での確認が必要です。
