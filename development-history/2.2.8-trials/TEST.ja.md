# Outfit Gallery 2.2.7-hair-test2

Painter HairとYunaの髪の置き換えを、逆方向にも対応させた確認版です。
DLLバージョン: 2.2.7.2。test1の改善はユーザー確認済みで、逆方向の効果はこれから確認します。

## 導入

ゲームを終了してから、このZIPをMO2の別MODとして導入し、2.2.7およびhair-test1より後でDLLを上書きしてください。
DLLだけの差し替えなので、既存の設定・登録セット・画像をそのまま使えます。
戻す場合はこの確認版MODを無効にしてください。

## 確認する操作

1. Yunaを実装備にし、Painter Hairを含むセットを重ね着します。
   Painter Hairの髪が表示され、数秒待っても消えないか確認します。
2. 「実際の装備の外見に戻す」でYunaに戻るか確認します。
3. そのまま同じ重ね着→解除をもう1往復します。
4. 前回改善したPainter Hairを実装備→Outfit 174の重ね着も正常か確認します。

結果とOutfitGallery.logをお知らせください。診断行はHAIR-STAGE2です。

## デフォルト髪が固定される件

このDLLではFSMP設定を変更していません。別途FSMPの
「ウィッグ着用時に髪の物理を無効化」を一時的にOFFにして比較をお願いします。
現在の設定はONで、見た目でなく実装備の髪を判定するFSMP側の停止条件と整合します。
設定変更がすぐに反映されない場合はゲーム再起動後に比較してください。
OFFはFSMP全体に適用され、隠れているデフォルト髪の演算も残る場合があります。

この版は実装備の取り外し、所持品の生成・回収、共有レコードの優先度やスロットの書き換えを追加しません。
髪以外のモデルや持ち主が曖昧なもの、今回の重ね着範囲に含まれない実装備には新しい対処を適用しません。
