# Toggle2 — 頭装備・全身セットの解除
DLL 1.0.18.14 / ベース Toggle1 (1.0.18.13)

- 頭装備も、登録装備がすべて揃った状態で同じ写真を選ぶと解除できます。
- 全身セットの解除は「オプション → 再クリックで全身セットの解除を許可」をONにした場合だけ有効です。
- この項目は新規設定・既存設定とも初期OFFです。OFFでは全身セットを再クリックしても従来どおり装着します。
- ONにすると衣装全体が外れ、下着や裸になる場合があります。設定に説明を表示します。
- 設定はプレイヤー・フォロワー、通常着替え・重ね着で共通です。
- 小物・頭装備の解除は全身用の設定がOFFでも有効です。登録内容に身体の装備を含めた小物・頭装備セットも、その登録内容が解除対象となります。
- 一部が別装備へ変わっていたら、その装備を外すのではなく、通常のセット装着を行います。
- 重ね着では見た目だけ解除し、実装備と性能を保ちます。
- 自動着替えは装着のみです。再クリックによる解除を自動処理には使用しません。

ゲームを終了し、旧調査版に代えてZIPを導入してください。設定の初期化は不要です。
前の作業版・公開版を保存した独立版です。

## 実機確認
1. 全身セットは設定OFFのまま何度選んでも脱げないこと。
2. 頭装備と小物は装着→解除→再装着できること。
3. 必要なら全身解除をONにし、装着→解除を確認すること。
4. 設定をOFFへ戻し、ゲームを再起動してOFFが維持されること。
プレイヤーとフォロワー、通常着替えと重ね着の今回の追加操作は実機未検証です。
